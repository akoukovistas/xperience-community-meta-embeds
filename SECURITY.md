# Security policy

## Supported versions

This is a community package with a single supported line: the latest released version. Fixes are not backported.

## Reporting a vulnerability

Please **do not** open a public issue for a security problem.

Open a [private security advisory](https://github.com/akoukovistas/xperience-community-meta-embeds/security/advisories/new)
on this repository instead. If the report concerns markup that passes the sanitiser and should not, include the oEmbed
URL and the offending fragment.

The threat model, the sanitiser allowlists and what is deliberately out of scope are documented in
[docs/Security.md](docs/Security.md).

Vulnerabilities in Xperience by Kentico itself belong with Kentico, not here - see
[Kentico's security policy](https://github.com/Kentico/.github/blob/main/SECURITY.md).
